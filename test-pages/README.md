# Sagi Block Test Pages

本物の詐欺サイトを探しに行かず、ローカルで安全に検出を試すためのページです。

## 起動

Windows 側で:

```powershell
cd C:\path\to\sagi-block\test-pages
python -m http.server 8765
```

Python がなければ、任意の静的HTTPサーバーでこのフォルダを配信してください。

## URLs

- `http://127.0.0.1:8765/scareware.html`
  - 偽警告画面の検出テスト
  - 画面内に `偽セキュリティ警告` / `電話をかけさせよう` / `000-1234-5678` などを出します。
- `http://127.0.0.1:8765/notification.html`
  - Web通知許可の掃除テスト
  - 通知許可を求め、許可すると疑似通知を出します。

## Notes

- `localhost` / `127.0.0.1` はブラウザ上で安全なコンテキスト扱いになりやすく、通知APIのテストに向いています。
- 実際の詐欺サイトへアクセスしてテストするのは避けてください。広告ネットワークやリダイレクトで危険なファイルや追加通知許可に誘導されることがあります。
